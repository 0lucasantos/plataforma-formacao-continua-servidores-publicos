# Aprenda+ Frontend

Frontend inicial em HTML, CSS e JavaScript puro, integrado ao backend Express.

## Rodar

Em um terminal, suba o backend:

```bash
cd ../backend
npm run dev
```

Em outro terminal, suba o frontend:

```bash
cd ../plataforma-web
npm run dev
```

Acesse:

- Frontend: http://localhost:3000
- Backend: http://localhost:3001

## Login de teste

Use as credenciais configuradas no `backend/.env`.

- Servidor: `servidor@plataforma.com` / `servidor123`
- Admin: `admin@plataforma.com` / `admin123`
